Architected a production-grade streaming fraud detection system using **Kafka, Pathway, and River**, handling **70k+ txns/min** with **sub-40ms P95 latency**.

Deployed online learning algorithms tuned using Optuna for real-time drift adaptation, reducing false positives by **15--20%**.

Designed an automated retraining pipeline via **BigQuery, Celery, and W&B**, enabling **80% faster** model updates and zero-downtime deployment.
