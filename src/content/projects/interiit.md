Engineered key components of a real-time fraud detection platform built on **Kafka, Pathway, and River**, processing **70k+ transactions per minute** at **sub-40 ms P95 latency**.

Developed and tuned online learning models in **RiverML** using **Optuna** for real-time drift adaptation, reaching a final **F1 score of 0.92**.

Built an LLM-powered fraud re-analysis workflow with **SHAP-based root-cause reports** and natural-language explanations for flagged transactions.

Designed an automated retraining and deployment pipeline with **BigQuery, Celery, and Weights & Biases**, including health-monitoring triggers for degradation detection.
